# Groundwater Nitrate Prediction

## Overview

This repository supports research on groundwater nitrate nitrogen (NO₃⁻-N) prediction and spatial distribution analysis in the lower reaches of the Huangshui River, China.

The study integrates hydrochemical analysis, feature selection, machine learning, model interpretation, and GIS-based spatial prediction.

## Methods

- Spearman correlation analysis
- Self-Organizing Map (SOM) and Boruta feature selection
- Random Forest (RF) and Extreme Gradient Boosting (XGBoost)
- RF-XGBoost stacking with Ridge regression
- Model performance and robustness assessment
- SHAP-based model interpretation
- GIS-based spatial prediction
